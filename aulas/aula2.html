Aula 2 — Autenticação com Jetstream e introdução ao Livewire

Disciplina: Desenvolvimento Web com Laravel · Carga horária: 2h

Jetstream Livewire Aula 2 de 6

🔁 Revisão rápida — Aula 1

  • Criamos o projeto com composer create-project laravel/laravel cadastro-alunos — sem instalar nada global.
  • Configuramos DB_CONNECTION=sqlite no .env e criamos o arquivo database\database.sqlite.
  • Rodamos php artisan migrate para criar as tabelas básicas.
  • Subimos o projeto com php artisan serve e vimos a tela de boas-vindas em http://127.0.0.1:8000.

Se algum desses passos não funcionou, procure o professor antes de continuar — a Aula 2 depende do projeto já estar criado e rodando.

🎯 Objetivo da aula

Vamos adicionar autenticação completa (cadastro, login, perfil) ao nosso sistema usando o Jetstream, e entender o papel do Livewire — a tecnologia que vamos usar mais adiante para deixar o cadastro de alunos dinâmico, sem escrever JavaScript manualmente.

📚 Conceitos

O que é o Jetstream?

O Laravel Jetstream é um pacote oficial que entrega, pronto, um sistema completo de autenticação: login, cadastro, recuperação de senha, verificação de e-mail, edição de perfil, foto de perfil e até autenticação em dois fatores. Sem ele, teríamos que construir cada uma dessas telas manualmente.

O Jetstream oferece duas "stacks" (formas de montar a interface):

StackComo funciona
Livewire (a que vamos usar)Interface reativa em PHP, sem precisar escrever JavaScript separado
InertiaInterface construída com Vue.js, mais próxima de uma SPA tradicional

O que é o Livewire?

O Livewire é uma biblioteca que permite criar componentes de interface interativos (que atualizam a tela sem recarregar a página) escrevendo apenas PHP e Blade — sem precisar dominar um framework JavaScript como Vue ou React. Por trás dos panos, ele troca dados com o servidor automaticamente via requisições AJAX.

Vamos usá-lo pela primeira vez agora (via Jetstream) e depois, na Aula 6, vamos criar nosso próprio componente Livewire para a listagem de alunos.

Por que isso importa para o nosso CRUD: mais adiante, quando o usuário digitar um filtro de busca na lista de alunos, o Livewire vai atualizar os resultados na hora, sem precisar apertar um botão "buscar" nem recarregar a página.

🛠️ Passo a passo

1Abra o terminal na pasta do projeto 
cd cadastro-alunos
2Instale o pacote Jetstream via Composer 
composer require laravel/jetstream

Repare que este comando NÃO usa global — ele instala o Jetstream como dependência deste projeto específico, dentro da pasta vendor.

3Instale a stack Livewire do Jetstream 
php artisan jetstream:install livewire
4Instale as dependências de front-end 
npm install
npm run build
5Rode as novas migrations

O Jetstream adiciona campos e tabelas (como as de "times", se estiver habilitado). Vamos aplicar isso no nosso banco SQLite:

php artisan migrate
6Suba o projeto e teste o cadastro 
php artisan serve

Acesse http://127.0.0.1:8000/register, crie um usuário de teste e faça login. Explore a tela de Profile — ela já vem pronta, gerada pelo Jetstream/Livewire.

Deu erro ao rodar npm run build? Confirme que está na pasta correta do projeto (cadastro-alunos) e que o comando npm install terminou sem erros antes. Se precisar, rode npm install novamente.
