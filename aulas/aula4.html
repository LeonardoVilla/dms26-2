🎯 Objetivo da aula

Hoje vamos sair do Tinker e criar uma interface de verdade: uma rota e uma página Blade para listar todos os alunos, e um formulário para cadastrar novos alunos pelo navegador.

📚 Conceitos

Rotas

No Laravel, cada URL do site precisa estar associada a uma rota, definida no arquivo routes/web.php. A rota diz: "quando alguém acessar essa URL, execute esse método do Controller".

Controller

O Controller é a classe que recebe a requisição, conversa com o Model (banco de dados) e decide qual view mostrar. Já criamos o nosso na Aula 3 com a flag -c.

Blade Templates

O Blade é o motor de templates do Laravel. Ele permite escrever HTML misturado com comandos PHP simplificados, como @foreach, @if e {{ $variavel }}. Arquivos Blade ficam em resources/views e terminam com .blade.php.

Layouts e Componentes Blade

Em vez de repetir o mesmo HTML (menu, rodapé, etc.) em cada página, o Blade permite criar componentes reutilizáveis. O Jetstream já trouxe um layout de aplicação pronto (x-app-layout) que vamos aproveitar. Um componente é usado assim: <x-app-layout>...conteúdo...</x-app-layout>. Isso evita duplicar código e mantém a aparência consistente entre as páginas.

🛠️ Passo a passo

1Crie as rotas

Abra routes/web.php e adicione, dentro do grupo protegido por autenticação (perto das rotas do dashboard):

use App\Http\Controllers\AlunoController;

Route::middleware(['auth'])->group(function () {
    Route::get('/alunos', [AlunoController::class, 'index'])->name('alunos.index');
    Route::get('/alunos/novo', [AlunoController::class, 'create'])->name('alunos.create');
    Route::post('/alunos', [AlunoController::class, 'store'])->name('alunos.store');
});
2Implemente os métodos no Controller

Abra app/Http/Controllers/AlunoController.php:

use App\Models\Aluno;
use Illuminate\Http\Request;

class AlunoController extends Controller
{
    public function index()
    {
        $alunos = Aluno::latest()->get();
        return view('alunos.index', compact('alunos'));
    }

    public function create()
    {
        return view('alunos.create');
    }

    public function store(Request $request)
    {
        $dados = $request->validate([
            'nome' => 'required|string|max:255',
            'email' => 'required|email|unique:alunos,email',
            'cpf' => 'required|digits:11|unique:alunos,cpf',
            'data_nascimento' => 'required|date',
            'telefone' => 'required|string|max:20',
            'curso' => 'required|string|max:255',
        ]);

        Aluno::create($dados);

        return redirect()->route('alunos.index')->with('status', 'Aluno cadastrado com sucesso!');
    }
}

Vamos estudar a validação com mais detalhes na Aula 5. Por hoje, ela já garante que nenhum campo obrigatório fique vazio.

3Crie a pasta e a view de listagem

Crie o arquivo resources/views/alunos/index.blade.php:

<x-app-layout>
    <div class="max-w-4xl mx-auto py-6">
        <h1 class="text-xl font-bold mb-4">Alunos cadastrados</h1>

        @if (session('status'))
            <div class="mb-4 text-green-600">{{ session('status') }}</div>
        @endif

        <a href="{{ route('alunos.create') }}" class="text-blue-600 underline">+ Novo aluno</a>

        <table class="w-full mt-4 border">
            <thead>
                <tr>
                    <th class="border p-2">Nome</th>
                    <th class="border p-2">E-mail</th>
                    <th class="border p-2">Curso</th>
                </tr>
            </thead>
            <tbody>
                @foreach ($alunos as $aluno)
                    <tr>
                        <td class="border p-2">{{ $aluno->nome }}</td>
                        <td class="border p-2">{{ $aluno->email }}</td>
                        <td class="border p-2">{{ $aluno->curso }}</td>
                    </tr>
                @endforeach
            </tbody>
        </table>
    </div>
</x-app-layout>
4Crie a view do formulário de cadastro

Crie o arquivo resources/views/alunos/create.blade.php:

<x-app-layout>
    <div class="max-w-xl mx-auto py-6">
        <h1 class="text-xl font-bold mb-4">Novo aluno</h1>

        <form method="POST" action="{{ route('alunos.store') }}">
            @csrf
            <label>Nome</label>
            <input type="text" name="nome" value="{{ old('nome') }}" class="border w-full mb-2">

            <label>E-mail</label>
            <input type="email" name="email" value="{{ old('email') }}" class="border w-full mb-2">

            <label>CPF</label>
            <input type="text" name="cpf" value="{{ old('cpf') }}" class="border w-full mb-2">

            <label>Data de nascimento</label>
            <input type="date" name="data_nascimento" value="{{ old('data_nascimento') }}" class="border w-full mb-2">

            <label>Telefone</label>
            <input type="text" name="telefone" value="{{ old('telefone') }}" class="border w-full mb-2">

            <label>Curso</label>
            <input type="text" name="curso" value="{{ old('curso') }}" class="border w-full mb-4">

            <button type="submit" class="bg-red-600 text-white px-4 py-2 rounded">Salvar</button>
        </form>
    </div>
</x-app-layout>
Não esqueça o @csrf: o Laravel exige um token de proteção contra ataques CSRF em todo formulário POST. Sem ele, o envio será bloqueado.
5Teste no navegador 
php artisan serve

Acesse http://127.0.0.1:8000/alunos, clique em "+ Novo aluno", preencha o formulário e confira se ele aparece na listagem.
