🎯 Objetivo da aula

Hoje começamos a parte principal do projeto: vamos criar a tabela de alunos no banco de dados e o Model que o Laravel usa para conversar com essa tabela em PHP, usando o Eloquent ORM.

📚 Conceitos

Migration

Uma migration é um arquivo PHP que descreve uma alteração no banco de dados (criar tabela, adicionar coluna, etc). Elas funcionam como um "histórico versionado" do seu banco — em vez de você criar tabelas manualmente clicando em uma ferramenta gráfica, você escreve código que qualquer colega (ou o professor) pode rodar e chegar exatamente na mesma estrutura de banco.

Model (Eloquent)

Um Model é uma classe PHP que representa uma tabela do banco. O Laravel usa um ORM chamado Eloquent, que permite trabalhar com registros do banco como se fossem objetos PHP comuns — sem escrever SQL manualmente. Por exemplo: Aluno::all() busca todos os alunos, e Aluno::create([...]) insere um novo registro.

🛠️ Passo a passo

1Gere o Model, a Migration e o Controller de uma só vez

O Artisan tem um atalho que cria os três arquivos juntos:

php artisan make:model Aluno -mc

-m gera a migration, -c gera o controller. Vamos usar o controller só a partir da Aula 4.

2Edite o arquivo da migration

Abra o arquivo criado em database/migrations/xxxx_xx_xx_create_alunos_table.php e ajuste o método up():

public function up(): void
{
    Schema::create('alunos', function (Blueprint $table) {
        $table->id();
        $table->string('nome');
        $table->string('email')->unique();
        $table->string('cpf', 11)->unique();
        $table->date('data_nascimento');
        $table->string('telefone');
        $table->string('curso');
        $table->timestamps();
    });
}
3Rode a migration 
php artisan migrate

Isso cria a tabela alunos dentro do arquivo database.sqlite.

4Configure o Model Aluno

Abra app/Models/Aluno.php e defina quais campos podem ser preenchidos em massa (fillable):

class Aluno extends Model
{
    protected $fillable = [
        'nome',
        'email',
        'cpf',
        'data_nascimento',
        'telefone',
        'curso',
    ];
}
Por que $fillable é importante: por segurança, o Eloquent bloqueia por padrão o preenchimento em massa de campos. Sem declarar $fillable, um comando como Aluno::create($request->all()) lançaria um erro de "mass assignment".
5Teste o Model no Tinker

O Tinker é um console interativo do Laravel — ótimo para testar código PHP rapidamente:

php artisan tinker

Dentro do Tinker, crie um aluno de teste:

Aluno::create([
    'nome' => 'Maria Silva',
    'email' => 'maria@teste.com',
    'cpf' => '12345678900',
    'data_nascimento' => '2000-05-10',
    'telefone' => '65999998888',
    'curso' => 'Desenvolvimento Web',
]);

Depois confira se foi salvo:

Aluno::all();

Para sair do Tinker, digite exit.

Dica: se quiser ver a tabela e os dados de forma visual, ferramentas como DB Browser for SQLite (gratuita) permitem abrir o arquivo database/database.sqlite diretamente.
