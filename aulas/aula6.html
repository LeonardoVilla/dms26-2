Aula 6 — Deixando a listagem dinâmica com Livewire

Disciplina: Desenvolvimento Web com Laravel · Carga horária: 2h

Hoje vamos evoluir a tela de listagem que já está funcionando — sem mexer no restante do CRUD.

🎯 Objetivo da aula

Última aula do curso! Vamos substituir a listagem estática de alunos por um componente Livewire, com um campo de busca que filtra os resultados em tempo real, sem recarregar a página — usando o que aprendemos sobre Livewire lá na Aula 2.

📚 Conceito: como o Livewire atualiza a tela sozinho

Um componente Livewire tem duas partes: uma classe PHP (com propriedades e métodos) e uma view Blade. Quando uma propriedade pública da classe muda — por exemplo, o texto digitado em um campo com wire:model — o Livewire reenvia essa informação ao servidor automaticamente, reprocessa a view e atualiza só o trecho necessário da página, sem recarregar tudo.

🛠️ Passo a passo

1Gere o componente Livewire 
php artisan make:livewire ListaAlunos

Isso cria dois arquivos: app/Livewire/ListaAlunos.php (classe) e resources/views/livewire/lista-alunos.blade.php (view).

2Implemente a classe do componente

Edite app/Livewire/ListaAlunos.php:

namespace App\Livewire;

use App\Models\Aluno;
use Livewire\Component;

class ListaAlunos extends Component
{
    public string $busca = '';

    public function delete($id)
    {
        Aluno::findOrFail($id)->delete();
    }

    public function render()
    {
        $alunos = Aluno::query()
            ->when($this->busca, function ($query) {
                $query->where('nome', 'like', '%' . $this->busca . '%')
                      ->orWhere('curso', 'like', '%' . $this->busca . '%');
            })
            ->latest()
            ->get();

        return view('livewire.lista-alunos', compact('alunos'));
    }
}

when() só aplica o filtro where se o campo busca não estiver vazio — assim, sem digitar nada, a lista completa aparece normalmente.

3Implemente a view do componente

Edite resources/views/livewire/lista-alunos.blade.php:

<div>
    <input
        type="text"
        wire:model.live="busca"
        placeholder="Buscar por nome ou curso..."
        class="border w-full mb-4 p-2"
    >

    <table class="w-full border">
        <thead>
            <tr>
                <th class="border p-2">Nome</th>
                <th class="border p-2">E-mail</th>
                <th class="border p-2">Curso</th>
                <th class="border p-2">Ações</th>
            </tr>
        </thead>
        <tbody>
            @forelse ($alunos as $aluno)
                <tr wire:key="aluno-{{ $aluno->id }}">
                    <td class="border p-2">{{ $aluno->nome }}</td>
                    <td class="border p-2">{{ $aluno->email }}</td>
                    <td class="border p-2">{{ $aluno->curso }}</td>
                    <td class="border p-2">
                        <a href="{{ route('alunos.edit', $aluno) }}" class="text-blue-600 underline">Editar</a>
                        <button
                            wire:click="delete({{ $aluno->id }})"
                            wire:confirm="Excluir este aluno?"
                            class="text-red-600 underline"
                        >Excluir</button>
                    </td>
                </tr>
            @empty
                <tr><td colspan="4" class="border p-2 text-center">Nenhum aluno encontrado</td></tr>
            @endforelse
        </tbody>
    </table>
</div>

wire:model.live envia cada tecla digitada ao servidor em tempo real. wire:click chama um método PHP do componente sem escrever JavaScript. wire:confirm mostra uma confirmação nativa antes de executar a ação.

4Use o componente na página de listagem

Substitua o conteúdo da tabela em resources/views/alunos/index.blade.php pela chamada do componente:

<x-app-layout>
    <div class="max-w-4xl mx-auto py-6">
        <h1 class="text-xl font-bold mb-4">Alunos cadastrados</h1>

        @if (session('status'))
            <div class="mb-4 text-green-600">{{ session('status') }}</div>
        @endif

        <a href="{{ route('alunos.create') }}" class="text-blue-600 underline">+ Novo aluno</a>

        <div class="mt-4">
            @livewire('lista-alunos')
        </div>
    </div>
</x-app-layout>
5Teste a busca dinâmica 
php artisan serve

Acesse /alunos e digite no campo de busca. Observe que a tabela filtra os resultados sem a página recarregar — isso é o Livewire em ação.
